Start an independent background subagent with a fresh conversation and this Driver's default configuration. It receives only your instructions as its first user message; parent conversation, settings and dynamically registered tools are not inherited. The child does not register a subagent tool. Returns task_id after initialization is ready. Read assistant content and labeled [subagent error] diagnostics with task_read; a task_id is not proof of task success. The child records its own history and stops after its round, while the task retains output until you manually task_finish. Finishing early cleans any remaining child Agent.
