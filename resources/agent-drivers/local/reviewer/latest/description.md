Start an independent background subagent for a focused task using this Agent's configuration and a balanced prefix of its conversation. The inherited transcript is reference material from the parent, not the child's own work. It runs the same initialization and does not register a subagent tool of its own. Returns task_id immediately; setup and inference continue in the background by reading the parent directly after the task result is returned. Read nonempty assistant content and explicitly labeled [subagent error] diagnostics with task_read; reasoning, tool results, compact messages and user input are not added to the task output. A returned task_id is an acceptance receipt, not evidence of success. Host/setup failures are also exposed by the existing task error field. The child Agent stops after its round, while its task retains output until you manually task_finish. Finishing early also cleans any remaining child Agent.
